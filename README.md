## Clinica_Moron
Base de Datos_Oracle 
## Clínica Privada Morón, a continuación te presento el contenido explicado paso a paso:   
1. ## Limpieza Previa
   El script incluye un bloque comentado al inicio para eliminar las tablas existentes (citas, pacientes, personal_medico) y el paquete (pkg_clinica_gestion) en caso de que necesites reiniciar o recrear el esquema desde cero.
3. ## Creación de Estructuras y Tablas AvanzadasSe crean las tres tablas principales utilizando características modernas de Oracle (versión 12c en adelante) como columnas de identidad (GENERATED BY DEFAULT AS IDENTITY):
   4. ## personal_medico: Almacena los datos de los profesionales
      (matrícula única, nombre, apellido, rol validado por un CHECK, especialidad, email institucional y fecha de ingreso).   pacientes: Contiene la información personal y clínica básica de los pacientes (nombre, apellido, fecha de nacimiento, género, teléfono, email, dirección y grupo sanguíneo validado por restricciones).   citas: Gestiona las consultas médicas relacionando pacientes y personal médico mediante claves foráneas con eliminación en cascada (ON DELETE CASCADE), además de usar tipos de datos TIMESTAMP para la fecha/hora y CLOB para los motivos de consulta.   Índices de Optimización: Se crea un índice B-Tree sobre la fecha de las citas y un índice basado en funciones (UPPER(apellido)) para acelerar las búsquedas por apellido de pacientes sin distinción de mayúsculas/minúsculas.
5. Inserción de Datos Iniciales (MERGE)Se utiliza la sentencia MERGE INTO (Upsert) para poblar la tabla personal_medico con un conjunto inicial de profesionales (director, médicos, enfermera y ayudante) de forma segura, evitando duplicados si se ejecuta el script varias veces.
6. ## Creación del Paquete PL/SQL (pkg_clinica_gestion)El paquete divide su lógica en Especificación y Cuerpo:
   Procedimiento sp_generar_pacientes_masivos:Ejecuta un bucle (FOR) de 100 iteraciones para registrar pacientes ficticios de prueba.   Asigna dinámicamente géneros y grupos sanguíneos mediante estructuras condicionales (IF y CASE).   Incluye un bloque de manejo de excepciones (EXCEPTION) para capturar duplicados (DUP_VAL_ON_INDEX) de forma elegante y reportar errores generales mediante RAISE_APPLICATION_ERROR.   Función fn_obtener_ranking_medicos:Retorna un cursor de referencia (SYS_REFCURSOR).   Utiliza funciones analíticas avanzadas de Oracle (DENSE_RANK() OVER (ORDER BY ...) ) para clasificar a los médicos según su volumen de citas.
8.  Ejecución del Proceso MasivoSe activa la salida por consola con SET SERVEROUTPUT ON; y se ejecuta el procedimiento almacenado para generar e insertar los 100 pacientes en la base de datos.
9.  Consulta Analítica con CTE (Common Table Expressions)Al final, se ejecuta una consulta de ejemplo que utiliza la cláusula WITH (resumen_citas) combinada con funciones de ventana (ROW_NUMBER() OVER (PARTITION BY ... ORDER BY ...)) para clasificar el historial de consultas de los pacientes particionando por su género y fecha de nacimiento.
